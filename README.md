# SmartAtReply

AstrBot 插件：根据用户消息中是否 @ 了机器人，决定机器人回复时是否 @ 发送者。

## 功能

- 群聊中用户 @ 机器人 → 正常响应，但回复开头先 @ 发送者，再发送文本内容
- 未被 @ → 正常响应，回复为纯文本，不带 @
- 私聊消息视为"已提及"，正常纯文本回复
- 通过 `on_llm_response` 钩子在响应链开头插入 `At` 组件，不污染 LLM 历史记录

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| only_reply_when_mentioned | bool | false | 为 true 时，未被 @ 的群消息直接拦截不再回复 |
| reply_text | string | 你好，有什么可以帮你的吗？ | 已废弃（v1.1.0 起回复内容完全由正常流程生成） |

## 安装

将本目录放入 AstrBot 的 `data/plugins/` 下，重载插件即可。

## 说明

- v1.1.0：改为钩子方案，不再发送固定文本，正常 LLM 响应的第一句前插入 @ 发送者
- v1.0.0：初始版本（被 @ 时回复固定文本）
