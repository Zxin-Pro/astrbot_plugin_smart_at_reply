# SmartAtReply

AstrBot 插件：根据用户消息中是否 @ 了机器人，决定机器人回复时是否 @ 发送者。

## 功能

- 群聊中用户 @ 机器人 → 回复开头先 @ 发送者，再发送文本内容
- 未被 @ → 不拦截消息，走 AstrBot 正常回复流程（纯文本，不带 @）
- 私聊消息视为"已提及"，直接纯文本回复

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| only_reply_when_mentioned | bool | false | 为 true 时，未被 @ 的群消息直接拦截不再回复 |
| reply_text | string | 你好，有什么可以帮你的吗？ | 被 @ 时的回复内容 |

## 安装

将本目录放入 AstrBot 的 `data/plugins/` 下，重载插件即可。
